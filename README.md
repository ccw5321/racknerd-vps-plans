## 不同需求怎么挑

**跑脚本、挂代理、定时任务、编译测试**：768M 或 1G 的最低档就够。这类用途吃的是在线时间和 IP，1T 月流量基本用不完，多花的钱买不到体验差别。

**一个内容站或小型独立站**：1.5G 到 2G 内存起步，硬盘挑 25G 以上。数据库和系统本身会占掉一部分，768M 跑 WordPress 加几个插件会比较紧张。

**多个站点、几个 Docker 容器**：2核 2G 是这条线的下限，硬盘往 35G 以上看。官方的一键应用目录里有 Docker + Portainer，也有 CyberPanel、CloudPanel 这类面板，装完再自己加站点很方便。

**拿它当存储盘**：RackNerd 另有犹他州盐湖城机房的大硬盘存储型服务器，那是另一条产品线，不在上面的年付款式里。

## 常见问题

**支持哪些付款方式？** 支付宝和 PayPal，多个来源一致。对没有双币信用卡的学生和个人开发者，这是它被反复推荐的实际原因之一。

**能装 Windows 吗？** 官方列出的系统模板全是 Linux，只有自定义 ISO 需要开工单申请。Windows 能不能装、授权怎么算，资料里没有明确说明，别默认它支持。

**多久能开通？** 付款后即时部署，不需要等人工审核。
